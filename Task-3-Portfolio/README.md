# 🌐 Personal Developer Portfolio — Idiris Abdikadir

A modern, fully responsive personal portfolio website built with pure **HTML**, **CSS**, and **JavaScript**. Designed with a dark aesthetic, glowing ambient accents, smooth animations, and a clean professional layout.

---

## 🚀 Live Demo

> Open `index.html` in your browser to view the portfolio locally.

---

## ✨ Features

- **Dark Mode Design** — Deep navy/indigo color scheme with ambient glow effects
- **Smooth Scrolling** — Native smooth-scroll navigation between sections
- **Scrollspy Navigation** — Active nav link updates as you scroll through sections
- **Mobile Responsive** — Fully responsive layout across all screen sizes
- **Animated Skill Bars** — Progress bars animate when scrolled into view (Intersection Observer)
- **Contact Form** — Opens your default email client pre-filled with the message
- **Back to Top Button** — Appears on scroll, smooth returns to top
- **Toast Notifications** — Visual feedback on form submission
- **Mobile Menu** — Hamburger toggle menu for small screens
